# Playground GECS

[Godot GECS - csprance](https://github.com/csprance/gecs)

This repository is a dedicated learning environment and playground for experimenting with Godot GECS. Designed as a safe space to master ECS concepts through hands-on experimentation, the repo contains various ```example_<name>``` directories. Each of these subfolders acts as an isolated sandbox, ranging from minimal learning projects to functional game examples, allowing you to break things and test patterns without affecting the rest of the project.
